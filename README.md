# tempitp
Simple home thermometer with BMP280 and ESP32 S2 mini

Building and uploading is happening via the PlatformIO extension for VS Code

The project is using the [Wokwi](https://marketplace.visualstudio.com/items?itemName=wokwi.wokwi-vscode) extension for VS Code
and its supported "local configuration" option.

Note:
The Wokwi extension also requires additional license information to be added!
For further info check this guide:
[Wokwi Getting Started Docs](https://docs.wokwi.com/vscode/getting-started)
